# POS ร้าน โคตร เทพ — เวอร์ชัน 3.7

Google Sheets เป็นฐานข้อมูล, Google Apps Script เป็น API, และโฟลเดอร์ `public/` เป็นหน้าเว็บสำหรับ Netlify

## สิ่งที่เพิ่มและแก้ในรุ่นนี้

- ตั้งขนาดใบเสร็จ/ใบแจ้งหนี้เป็น A4 หรือ 80 มม. ที่เมนูตั้งค่า; ใบเสนอราคาและใบรายการตำแหน่งสินค้าใช้ A4
- เก็บชั้น/ตำแหน่งของสินค้า แสดงในหน้าและเอกสาร และพิมพ์รายการตำแหน่งได้
- เปิดใบเสนอราคาแบบจองหรือไม่จองสินค้า กำหนดวันหมดอายุ ยกเลิก และแปลงเป็นขายเชื่อ (Invoice) หรือขายสด/โอน (Receipt)
- ยอดจองจากใบเสนอราคาที่เปิดอยู่และยังไม่หมดอายุหักออกจากจำนวนที่ขายได้
- รายงานเลือกวันนี้ เดือนนี้ เดือนที่แล้ว ปีนี้ ปีที่แล้ว หรือวันที่เอง; Owner/แอดมินดาวน์โหลด Excel `.xlsx` และ PDF ได้
- Owner เท่านั้นที่ตั้งเพดานส่วนลด ใช้ PIN Owner อนุมัติรายการที่เกินเพดาน รวมถึงสำรองข้อมูล Archive และ Factory Reset
- Admin/Owner เปลี่ยนชื่อร้านและเลือก VAT Inclusive หรือ VAT Exclusive ได้
- เปิด/ปิดการแสดงสินค้าที่เคยขายได้ โดยเก็บประวัติและยอดคงเหลือไว้
- ป้องกันการบันทึกบิลขายซ้ำด้วย `requestId`; ราคาขายตรวจจากข้อมูลสินค้าฝั่ง API
- ใบลดหนี้คืนสินค้าใช้ราคาขายสุทธิที่ลูกค้าจ่าย รวมส่วนลดท้ายบิลและ VAT ตามสัดส่วน
- คืนเงินสดและยกเลิกบิลเงินสดลงกะปัจจุบันและตรวจเงินคงเหลือก่อนบันทึก
- สำรอง Google Spreadsheet ทั้งไฟล์ก่อน Archive/Reset; Archive เฉพาะธุรกรรมที่ปิดแล้วก่อนวันที่เลือก และทำยอดยกมาของ StockMoves

## อัปเดตจากเวอร์ชัน 3.6

1. สำรอง Google Spreadsheet และเก็บ ZIP รุ่นเดิมไว้ก่อนอัปเดต
2. ใน Apps Script ให้แทนที่ไฟล์ `.gs` เดิมทั้งหมดด้วยไฟล์ใน `apps-script/` และเพิ่มไฟล์ใหม่ `Quotations.gs` กับ `DataManagement.gs`
3.  รัน `setupAll()` หนึ่งครั้งเพื่อเพิ่มชีต/คอลัมน์/ตัวนับใหม่โดยไม่ลบข้อมูลเดิม และสร้างล็อตยกมาสำหรับสินค้าที่มีจำนวนแต่ยังไม่มีล็อต โฟลเดอร์หลักใน Google Drive จะใช้ชื่อ `ฐานข้อมูล` เสมอ หากระบบมีโฟลเดอร์เดิมที่บันทึก ID ไว้ จะเปลี่ยนชื่อโฟลเดอร์นั้นโดยไม่สร้างโฟลเดอร์ใหม่
4. หากมีแอดมินรุ่นเดิม ระบบจะย้ายแอดมินที่ใช้งานอยู่คนแรกเป็น Owner และบังคับเปลี่ยน PIN เมื่อเข้าระบบ หากยังใช้ PIN เริ่มต้น `1234` ระบบจะเปลี่ยนเป็น PIN ชั่วคราวใหม่และแสดงใน Execution log ของ `setupAll()` หากเป็นฐานข้อมูลใหม่ ระบบสร้าง Owner `U001` พร้อม PIN ชั่วคราว 6 หลักใน log เดียวกัน
5. Deploy Apps Script เป็น **เวอร์ชันใหม่** เพื่อให้ API ใหม่ทำงาน; URL `/exec` เดิมใช้ต่อได้
6. อัปโหลดไฟล์ใน `public/` ชุดใหม่นี้ทั้งหมดไปยังที่เผยแพร่เว็บ แล้วรีโหลดหน้าเว็บ
7. Owner ตรวจข้อมูลร้าน ตั้งขนาดกระดาษ วิธีคำนวณ VAT และเพดานส่วนลดในหน้า **ตั้งค่า**

ไฟล์ `public/js/config.js` ในชุดนี้คง URL API เดิมของ ZIP ต้นทางไว้ ตรวจ URL ให้ตรงกับ Apps Script ที่ Deploy ก่อนใช้งาน

## วิธีใช้ใบเสนอราคา

เข้าเมนู **ใบเสนอราคา** เลือกลูกค้า สินค้า วันหมดอายุ และเลือกว่าจะจองสต็อกหรือไม่ ใบที่จองจะกันจำนวนสินค้าในระบบจนกว่าจะหมดอายุ ยกเลิก หรือยืนยันขาย เมื่อยืนยันขาย เลือก **ซื้อเชื่อ** เพื่อออกใบแจ้งหนี้ หรือเลือก **เงินสด/โอน** เพื่อออกใบเสร็จรับเงิน

การตั้ง VAT ในใบเสนอราคาจะถูกเก็บเป็นยอดของใบเสนอราคานั้น เมื่อยืนยันขาย ยอดจะยังตรงกับเอกสารที่เสนอแม้ร้านเปลี่ยนการตั้งค่า VAT ภายหลัง

## Backup, Archive และ Factory Reset

- **สำรองข้อมูลตอนนี้:** สร้างสำเนา Google Spreadsheet ในโฟลเดอร์ `ฐานข้อมูล` ที่ `setupAll()` ตั้งไว้
- **Archive:** Owner เลือกวันตัด ยืนยันด้วยคำว่า `ARCHIVE` และ PIN ระบบสำรองทั้งไฟล์ก่อน แล้วลบเฉพาะบิลขาย/ซื้อที่ชำระครบและไม่มีเอกสารต่อเนื่องหลังวันตัด รวมถึงธุรกรรมเก่าที่ปิดแล้ว ระบบเก็บสินค้า ลูกค้า ผู้ขาย ล็อตสต็อกที่ยังเหลือ รายการที่ยังค้าง และข้อมูลบัญชีไว้
- **Factory Reset:** Owner ยืนยันด้วยคำว่า `RESET` และ PIN ระบบสำรองทั้งไฟล์ก่อนเคลียร์ข้อมูลทำงาน แล้วเก็บบัญชี Owner ปัจจุบันและประวัติไฟล์สำรองไว้
- ประวัติ Archive/Reset และลิงก์ไฟล์สำรองอยู่หน้า **ตั้งค่า** หากสถานะ `IN_PROGRESS` ค้าง ให้ตรวจไฟล์สำรองและข้อมูลในชีตก่อนทำรายการซ้ำ

Archive และ Reset เป็นงานที่กระทบข้อมูลจริง ควรทดลองกับสำเนา Spreadsheet ก่อนใช้กับร้านจริง โดยเฉพาะฐานข้อมูลที่มีการแก้ชีตด้วยมือ
